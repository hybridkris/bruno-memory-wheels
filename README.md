# Bruno Memory Wheels

**[Open the simulator](https://hybridkris.github.io/bruno-memory-wheels/)**

Giordano Bruno's five memory wheels from *De umbris idearum* (Paris, 1582) as an interactive 3D instrument: five card
discs of 150 two-letter cells each, outermost the agents, then actions, insignia, adstantia and circumstantiae
(*Opera latine conscripta* II.i, Naples 1886, p. 122). The outer wheel stays, the inner ones turn, and a combination is
read along one radius. One number, the drive count, poses every disc and fills every panel: 150⁵ = 75 937 500 000
combinations.

Left alone, the page tours itself. Any click, drag, scroll or key hands it to you; 25 s of quiet hands it back.
Drag to orbit, scroll to zoom, H hides the panels, Q steps the quality.

What is Bruno's: the wheel structure, the letters, the cell scheme and the four 150-item lists, transcribed from the
1886 edition's OCR (archive.org `jordanibruninola2pt1brun`). That edition misprints the inventors list's codes from
no. 41 on; the page shows the printed code beside each. What is a reconstruction: the odometer drive, the index arm and
every dimension in millimetres.

`index.html` is one self-contained file, with three.js, the fonts and the data inlined. Licences for what it bundles
are in `licenses/`: three.js (MIT), the teardown kit it was built with (MIT), JetBrains Mono and Inter (SIL OFL 1.1).
